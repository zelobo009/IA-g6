# Airbnb Predictor App for Portugal

A dynamic pricing and booking demand prediction tool for Airbnb hosts in Portugal. This project uses machine learning (Random Forest Regression and Classification via `scikit-learn`) to predict optimal nightly prices and the probability of a listing being booked based on location, seasonality, property characteristics, and local events.

The user interface is built with Streamlit, providing an interactive dashboard to view market trends, manage properties, and simulate pricing scenarios.

## Project Structure

* `generate_data.py`: A synthetic data generator that creates a realistic dataset of Airbnb listings, prices, and occupancy states based on market rules and probabilities.
* `train_model.py`: The machine learning pipeline that preprocesses the data, trains the models (Price Regressor and Occupancy Classifier), and saves them for production use.
* `app.py`: The interactive Streamlit web application.
* `airbnb_data.csv`: The dataset generated by the script (created automatically).
* `airbnb_models.pkl`: The saved machine learning models and preprocessing pipeline (created automatically).

## 🛠️ Installation Instructions

### 1. Prerequisites
Ensure you have **Python 3.8 or higher** installed on your machine.

### Installation commands

```bash
pip install pandas numpy scikit-learn streamlit matplotlib
```

### Run commands

```bash
python generate_data.py

python train_model.py

streamlit run app.py
```
